# Current authorities at program start

- public React/map composition API: Maps TypeScript
- dataset/layer runtime: Maps
- supported point aggregation/index queries: Maps Rust/WASM when initialized; explicit no-WASM/SSR fallback remains
- point/cluster render semantics: Maps render frame
- independent reference pixel backend for point/clusters: Canvas2D
- camera/projection-to-screen/basemap/tile lifecycle: MapLibre
- broad production layer rendering: primarily MapLibre

Update this document only when an authority transfer is actually proven and integrated.
