# Engine program status

The first-party engine program is active under epic #75.

Current proven foundation before this program:

- Maps-owned React/public API and dataset/layer runtime;
- first-party `maps-core` / `maps-wasm` workspace;
- Rust/WASM authoritative supported point aggregation;
- Maps-owned point/cluster render-frame semantics;
- independent Canvas2D point/cluster pixel backend;
- MapLibre still owns camera/basemap/tile lifecycle and most production rendering.

Active foundation branch: `feat/maps-engine-foundation` (Milestone A / #76 / #82).

Do not describe the project as a MapLibre replacement until the milestone exit criteria in `docs/engine-roadmap.md` are actually proven.
