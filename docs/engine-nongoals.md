# Engine non-goals

- Rebuild MapLibre feature-for-feature before useful independent milestones exist.
- Introduce a generic visualization/scene-graph authority into Maps.
- Move browser/DOM/WebGPU device semantics into `maps-core`.
- Keep TypeScript and Rust implementations simultaneously authoritative for the same map result.
- Treat WebGPU availability as proof that WebGPU is the correct backend for a workload.
- Invent proprietary tile/style formats when established standards fit.
- Preserve old implementations, baselines or fallback paths after their intentional replacement is proven merely because deletion is inconvenient.
